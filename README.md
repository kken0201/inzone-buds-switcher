# inzone-buds-switcher

Sony INZONE Buds（WF-G700N）を USB ドングルで使うための Windows 11 用常駐アプリです。

- 🎧 イヤホンをケースから出すと、出力を INZONE Buds に自動で切り替えます
- 🔈 ケースに戻すと、元の出力（スピーカーなど）に自動で戻します
- 🔔 切り替えたときに通知します
- 🔋 システムトレイに左右イヤホンとケースのバッテリー残量を表示します

インストールは不要です。exe ファイル 1 つで動きます。

## ダウンロードと起動

1. [Releases](https://github.com/kken0201/inzone-buds-switcher/releases/latest) から `inzone-buds-switcher-vX.Y.Z.zip` をダウンロードします
2. zip を展開し、`inzone-buds-switcher.exe` を好きなフォルダに置きます
3. `inzone-buds-switcher.exe` をダブルクリックします

画面右下のシステムトレイ（時計の近く、隠れているときは `^` の中）に丸いアイコンが出たら起動しています。ウィンドウは開きません。

### 「Windows によって PC が保護されました」と表示されたら

このアプリにはコード署名をしていないため、初回の起動時に Windows SmartScreen の警告が出ます。次の手順で起動できます。

1. 警告の画面で「詳細情報」をクリックします
2. 下に出る「実行」ボタンをクリックします

2 回目からは表示されません。

## 使い方

トレイアイコンをクリックするとメニューが開きます。

| アイコン | 状態 |
|---|---|
| 緑の円 | イヤホンが接続中 |
| 灰色の円 | イヤホンが切断中（ケースの中） |
| 灰色の輪 | ドングルが見つからない、または確認中 |

アイコンにマウスを重ねると、バッテリー残量（L：左、R：右、C：ケース）が表示されます。

### 最初にすること

ほとんどの場合、設定は不要です。初めてイヤホンをつないだとき、それまでの出力（スピーカーなど）を「切断時の出力」として自動で覚え、通知で知らせます。

戻し先を変えたいときは、メニューの「切断時の出力」から選ぶか、戻したいデバイスを Windows の既定の出力にしてから「今の出力を切断時の出力にする」を選びます。

### メニュー

| 項目 | 内容 |
|---|---|
| 自動切り替え | オフにすると出力を切り替えません |
| 接続時の出力 | イヤホンを出したときに切り替える先（通常は「INZONE Buds - Game」） |
| 切断時の出力 | イヤホンをケースに戻したときに戻す先 |
| 今の出力を切断時の出力にする | 今の既定の出力を戻し先にします |
| 既定の通信デバイスを Chat にする | Discord など、出力を「Default」にした通話アプリの音を Chat から出します。INZONE で Game と Chat の音量を別々に調節できます。オンにすると、切断時に Windows の「既定の通信デバイス」も切断時の出力に戻します |
| 切り替えを通知 | 切り替えたときに通知します。⚠ の警告はオフでも表示します |
| バッテリー低下を通知 | 左右どちらかのイヤホンの残量が少なくなったら通知します |
| Windows 起動時に開始 | パソコンの起動時に自動で起動します |
| 自動で更新する | 新しいバージョンが出たら、自動で入れ替えて起動し直します |
| 更新を確認 | すぐに新しいバージョンを確認し、あれば入れ替えて起動し直します。「自動で更新する」がオフでも使えます |
| ログフォルダを開く | 不具合を報告するときに、ここにあるログを添えてください |
| 終了 | アプリを終了します |

### 知っておくとよいこと

- イヤホンを使っている間に手動で出力を変えた場合、ケースに戻しても出力を戻しません
- 全画面のゲーム中は、Windows の仕様で通知が表示されません
- INZONE Hub と同時に起動しても動きます
- 新しいバージョンは 1 日 1 回確認します。更新したときは通知でお知らせします。exe を `C:\Program Files` など書き込めないフォルダに置くと更新できないので、ドキュメントやデスクトップなどのフォルダに置いてください
- exe を別のフォルダに移したら、「Windows 起動時に開始」をいったんオフにしてからオンにし直してください

## アンインストール

1. メニューの「Windows 起動時に開始」をオフにします
2. 「終了」を選びます
3. exe を削除します。設定とログも消す場合は、`%APPDATA%\inzone-buds-switcher`（設定）と `%LOCALAPPDATA%\inzone-buds-switcher`（ログ）のフォルダを削除します
